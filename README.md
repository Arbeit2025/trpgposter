# TRPG予告ポスターメーカー（trpgposter）

TRPG セッション告知用の「次回予告」風ポスター画像（1200x630 PNG）を合成するツールです。SNS への投稿画像づくりを想定しています。

## 使い方

1. タイトル、キャッチコピー、次回予告の一文、テーマ色（黒／赤／青／金）を入力します。
2. 任意で立ち絵画像（PNG/JPEG/WebP）をアップすると、右側に大きく配置されます。
3. 「ポスターを作る」を押すと PNG がダウンロードされます。

## フォントについて

日本語表示のため、実行時に Noto Sans CJK（notofonts の GitHub リポジトリ）からフォントファイルを取得し、`/tmp` にキャッシュして使います。初回生成時はダウンロードのため少し時間がかかります。取得に失敗した場合は、その旨のエラーを表示します。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

テストではフォント取得を行わず、ローカルの英字フォント（DejaVu Sans）で合成を確認しています。

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- フォント取得は外部サイト（GitHub）への通信に依存します。オフライン環境ではポスターを生成できません（エラーを表示します）。
- レイアウトは固定テンプレートです。長いタイトルや一文は自動で折り返しますが、3行／2行を超える分は表示されません。
- 立ち絵は縦幅いっぱいに拡大・配置するだけの簡易合成です。切り抜き（透過処理）の編集はしません。
- アップロード画像は保存しません。
